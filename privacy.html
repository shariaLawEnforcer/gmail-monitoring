Privacy Policy

Last updated: October 23, 2026

Gmail Monitoring is a personal, non-commercial tool used only by its developer, Alsyl Enriquez, on his own Google accounts.

What data it accesses

With the read-only Gmail scope (gmail.readonly), it reads email metadata (sender, subject, date) and message content to create a daily summary.

How data is used and stored

  • Email data is used only to generate summaries for the account owner.
  • Access tokens are stored locally on the developer's computer.
  • No data is sold, shared with third parties, or used for advertising.
  • The app cannot send, delete, or modify email.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.

Gmail Monitoring's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
